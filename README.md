# Ghos-Ti's Spell Vault

Welcome to the central portal for cataloging, managing, and inscribing powerful spells, ancient scrolls, and rare grimoires.

## Description
This website is built using ASP.NET Core MVC to manage an online repository for magical spells and arcane artifacts.

## Upcoming Features
- Bootstrap 5 magical interface styling
- Full CRUD operations for spell inscriptions using Entity Framework Core
- Arcane user authentication and shopping cart sessions

## How to Get Started
1. Clone or download the repository from GitHub.
2. Install the .NET 9.0 SDK.
3. Open and run the project using Visual Studio 2022.

## Technologies Used
- ASP.NET Core MVC (.NET 9)
- Entity Framework Core
- Bootstrap 5
- C# / HTML5 / CSS3
